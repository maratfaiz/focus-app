# Refocus — блокировщик отвлекающих приложений и сайтов для iOS

Функциональный клон приложения категории «app blocker» (по мотивам Refocus: Block Apps & Websites) на SwiftUI и Apple Screen Time API. Учебный проект: весь код написан с нуля.

## Возможности

- **Блокировка приложений** — любые приложения и целые категории через системный `FamilyActivityPicker` (TikTok, Instagram, YouTube, Telegram и т. д.).
- **Блокировка сайтов** — выбор в пикере или ручной ввод доменов (`youtube.com`, `reddit.com`, …) через веб-фильтр ManagedSettings.
- **Дневные лимиты** — например, TikTok 20 минут в день; по достижении порога приложение блокируется до конца дня.
- **Расписания** — по дням недели и времени (будни 08:00–13:00 → соцсети заблокированы), поддерживаются интервалы через полночь.
- **Быстрая блокировка** — «заблокировать всё развлекательное на 2 часа» одним нажатием, с обратным отсчётом.
- **Блокировка по местоположению** — геофенсинг: пришёл в библиотеку → YouTube и TikTok заблокированы, вернулся домой → ограничения сняты.
- **Статистика** — экранное время за день/неделю/месяц, динамика по дням и топ приложений через `DeviceActivityReport` (данные не покидают устройство).

### Strict Mode — способы снятия блокировки

| Способ | Как работает |
| --- | --- |
| Ожидание | Смотрите на таймер N секунд; свернули экран — отсчёт начинается заново |
| PIN-код | Отдельный PIN, задаётся в настройках |
| NFC-метка | Разблокировка только прикладыванием телефона к зарегистрированной метке (оставьте её дома) |
| Перепечатка текста | Нужно без единой ошибки перепечатать длинный занудный текст |
| Pomodoro | Не более N открытий в день по M минут с обязательным перерывом между сессиями |

## Архитектура

```
Refocus/                    основное приложение (SwiftUI)
  App/                      точка входа, AppModel (состояние и логика)
  Services/                 ScheduleService (DeviceActivity), LocationService (геофенсинг), NFCService
  Views/                    Фокус · Правила · Статистика · Настройки
Shared/                     модели и хранилище (App Group) — общие для всех таргетов
Extensions/
  Monitor/                  DeviceActivityMonitor: включает/выключает щиты по расписанию и лимитам
  ShieldConfiguration/      внешний вид экрана блокировки
  ShieldAction/             обработка кнопок на экране блокировки
  Report/                   DeviceActivityReport: рендер статистики
```

Как это работает:

1. Правила хранятся в `UserDefaults` App Group — их читают и приложение, и расширения.
2. `ScheduleService` регистрирует расписания/лимиты в `DeviceActivityCenter`; система будит расширение **Monitor** в начале/конце интервалов и при достижении порогов, и оно применяет или снимает «щиты» `ManagedSettingsStore` (у каждого правила свой именованный store).
3. Успешное прохождение challenge в Strict Mode ставит правило на паузу: щит снимается, а одноразовая активность возвращает его по окончании паузы, даже если приложение закрыто.

## Сборка

Требования: Xcode 15+, iOS 16.4+, аккаунт Apple Developer.

```bash
brew install xcodegen
xcodegen generate
open Refocus.xcodeproj
```

Затем в Xcode:

1. Укажите свой Team ID (Signing & Capabilities) для всех пяти таргетов.
2. Замените bundle-префикс `com.example` и App Group `group.com.example.refocus` на свои (App Group также в `Shared/SharedConstants.swift`).
3. **Family Controls**: для запуска на устройстве нужно entitlement `com.apple.developer.family-controls`. Для разработки оно включается в Xcode, для дистрибуции — запрашивается у Apple (форма «Family Controls & Personal Device Usage»).
4. Запускайте на **реальном устройстве** — Screen Time API в симуляторе не работает.

## Ограничения

- Screen Time API доступен только после разрешения пользователя и работает в рамках правил Apple: продвинутый пользователь может, например, удалить приложение или сбросить Screen Time.
- Экран-щит не может открыть другое приложение: кнопка «Разблокировать в Refocus» лишь помечает запрос — challenge открывается при следующем запуске Refocus.
- PIN и NFC-метка хранятся в App Group `UserDefaults` (для продакшена стоит перенести в Keychain).
- Синхронизация с Mac и iCloud не реализована.
